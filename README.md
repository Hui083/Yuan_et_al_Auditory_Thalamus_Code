# Yuan_et_al_Auditory_Thalamus_Code
Code for fiber photometry &amp; Neuropixels analysis in Yuan et al. (Astrocytic Cnr1 auditory paper). 
The example_data.mat file contains a small synthetic test dataset. Running fiber_analysis.m with this file will generate a demo figure.
These codes are standard .m scripts. You can run them using the free and open-source software GNU Octave.
